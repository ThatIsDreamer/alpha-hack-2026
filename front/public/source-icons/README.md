# Source marks

Retrieved 2026-10-23. Marks identify their respective sources; no affiliation is implied.

- Telegram: official vector from https://telegram.org/img/website_icon.svg. Usage guidance: https://telegram.org/press#telegram-logos.
- Publisher favicons: retrieved through https://www.google.com/s2/favicons?domain=DOMAIN&sz=64 for lenta.ru, kommersant.ru, rbc.ru, rosstat.gov.ru, moex.com, cbr.ru, publication.pravo.gov.ru, vedomosti.ru, worldbank.org, gdeltproject.org.

Served locally to avoid third-party requests for configured sources. Render at 16px in news metadata and 20px in source selection, with object-fit: contain. SVG scales without loss; raster originals retain their aspect ratios. New/unbundled article sources use a domain-only favicon request with no referrer and a neutral fallback on errors.
